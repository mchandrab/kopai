Tech Stack
Frontend: React + Vite, Tailwind CSS (untuk UI yang cepat dan modern).

Backend / Database & Auth: Supabase (PostgreSQL, Row Level Security, dan Auth bawaan).

Hosting & Edge Network: Tencent EdgeOne (untuk CDN statis global dan keamanan web).

AI Engine: Google Gemini API (Free Tier via Google AI Studio) untuk asisten finansial.

Scoring Logic: Algoritma pembobotan dinamis (weighted scoring) berbasis JavaScript/Supabase Database untuk kalkulasi kredit instan tanpa biaya server tambahan.
